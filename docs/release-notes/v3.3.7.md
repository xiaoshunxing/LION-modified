# LION 修改版 3.3.7（完整版 + lite）

本仓库首个 GitHub 发布版本为 **3.3.7**。只提供 3.3.7 安装包；下面附 3.3.1–3.3.6 的公开变更摘要，便于查看版本迭代，不提供旧版安装包。

## 本版变更（3.3.7）

- 界面文案精简：去重策略、区域编辑、服务设置等标签改回原版的简短风格，状态提示只保留必要信息。
- 新增 lite 版 **LION 修改版 lite**：以 3.3.1 的单区域界面为基础，客户端与设置对齐本版，可与完整版并存安装。
- 界面文案精简与 lite 版：xiaoshunxing。

## 版本迭代回顾（3.3.1–3.3.6）

### 3.3.6

- 新增“模型 / OCR 端点”设置：可编辑组合框，初始端点 `/ocr`，支持 `/ocr-acc`、`/layout-parsing`、自定义路径或完整 URL。
- 服务地址改为“基址 + 模型/端点”；老配置首次启动自动迁移，最终请求地址与 3.3.5 一致。
- “测试连接”与“获取模型列表”合并为一个按钮；模型列表优先 `/models`、`/v1/models`，否则回退 OpenAPI 端点列表。
- 支持 PaddleOCR-VL（`/layout-parsing`）的基础文本提取。

### 3.3.5

- 修复“跟读增量”在句子稳定后的重复播报；长台词里靠前位置的 OCR 抖动不再导致整段重念。
- 抖动判定改为长度自适应的编辑距离，并加入“模糊锚点”和“已播报内容相似度”兜底。
- 纯标点片段不再单独念出；数字/编号变化按新内容处理。

### 3.3.4

- 修复“稳定后朗读”的重复播报：缺标点、多空格、错一个字、偶发空帧不再让同一句被重念。
- 修复“跟读增量”的整段重读：按“已播报的内容前缀”定位，只念新增片段。
- 修复长句打字时被 10 秒保护提前打断的问题；空帧宽限处理。

### 3.3.3

- 新增分区去重策略：每个区域可选“经典（相似度）/ 稳定后朗读 / 跟读增量 / 关闭”。
- “稳定后朗读”用于逐字出现的 RPG 对话；“跟读增量”用于长对话，按标点分段释放。
- 老区域与迁移来的区域仍为“经典（相似度）”，行为与 3.3.2 一致。

### 3.3.2

- 新增多选区识别：识别区域从单一区域改成可增删改的区域列表，每个区域可单独勾选。
- 新增排队朗读；每个区域可单独选择识别目标与四向裁剪。
- 旧版单区域配置首次启动自动迁移；每个区域独立去重、独立提示失败。

### 3.3.1

- 识别后端由内置 PaddleOCR-json 改为外部 PaddleOCR HTTP 服务。
- 新增服务地址、令牌、请求超时、图像格式、最低识别分数等设置，以及“测试连接”。
- 移除内置引擎与包内未生效的 PIL，插件体积大幅下降；使用独立插件 ID，可与原版 LION 并存。

## 环境要求

- NVDA 2026.1 或更高（2026.2 已测试）。
- 推荐在本机部署 PaddleOCR HTTP 服务：延迟低，令牌不必出本机。下文以 `http://127.0.0.1:23353` 为例；请按实际部署替换地址、端点和令牌。插件不带 OCR 引擎或模型。
- 如果服务在另一台机器，请使用 HTTPS/反向代理并保护令牌；如果服务监听局域网地址，请用防火墙和令牌保护。

## 安装

1. 下载并打开对应的 `.nvda-addon`，在 NVDA 中安装并重启。
2. 打开 NVDA 菜单 → 选项 → 设置：完整版选 **LION 修改版**，lite 选 **LION 修改版 lite**，填写服务地址、端点与令牌。
3. 点“测试 / 获取模型”确认连接。

完整版与 lite 可以同时安装；默认热键相同，需要给其中一个换键。
