# LION 修改版 3.3.8（完整版 + lite）

这是 **LION 修改版** 的 3.3.8 发行版，完整版与 lite 版都提供安装包。
首个 GitHub 发布为 3.3.7；本版在 3.3.7 基础上加入配置档案全局化、每区域经典阈值、健壮性改进与 lite 修复。

## 本版变更（3.3.8）

- **配置节固定为基础配置（NVDA 2026.3+）**：插件不再随配置档案（Profile）与触发器变化；保存设置只写基础配置。
  首次安装/升级后需要重启 NVDA 生效；NVDA 2026.1/2026.2 仍为普通配置节（会随档案变化，建议在基础配置下修改）。
- **每区域「经典相似度阈值」**：完整版可在区域编辑对话框中单独设置，默认跟随全局默认值；其它去重方式（稳定后朗读、
  跟读增量、关闭）不受该阈值影响。
- **新增完整版「合并区域截图」选项（默认关闭）**：所有启用区域一次抓取再本地裁剪，减少抓屏次数；区域相隔很远时
  单次抓屏可能更慢，失败会自动退回逐区域抓屏。
- **健壮性**：设置面板「测试 / 获取模型」改为后台线程探测并回到界面线程显示，不再冻结 NVDA 主线程；OCR 客户端
  按设置缓存；停止识别可立刻唤醒轮询；设置面板注册/移除幂等，避免插件更新后出现重复面板。
- **lite 版修复**：长重复文本可能被反复朗读（相似度比较关闭 autojunk）、空帧后同一句不再朗读（新增 2 秒空帧宽限）、
  退出插件后仍在朗读（补 cancelSpeech）；全屏目标类型的死路径清理。
- **文档**：所有 AI 声明替换为 dsh 官方徽章（Powered by dsh）；开发文档与手册补充配置档案、逐区域阈值与排查说明。
- 兼容并测试 **NVDA 2026.3**（最低仍支持 2026.1）。

## 版本迭代回顾（3.3.1–3.3.7）

### 3.3.7

- 界面文案精简：去重策略、区域编辑、服务设置等标签改回原版的简短风格。
- 新增 lite 版 **LION 修改版 lite**，可与完整版并存安装。

### 3.3.6

- 新增“模型 / OCR 端点”设置；服务地址改为“基址 + 模型/端点”，老配置自动迁移。
- “测试连接”与“获取模型列表”合并；模型列表优先 `/models`、`/v1/models`，否则回退 OpenAPI 端点列表。
- 支持 PaddleOCR-VL（`/layout-parsing`）的基础文本提取。

### 3.3.5

- 修复“跟读增量”在句子稳定后的重复播报：抖动判定改为长度自适应的编辑距离，加入模糊锚点与相似度兜底。
- 纯标点片段不再单独念出；数字/编号变化按新内容处理。

### 3.3.4

- 修复“稳定后朗读”的重复播报：缺标点、多空格、错一个字、偶发空帧不再让同一句被重念。
- 修复“跟读增量”的整段重读；修复长句打字被 10 秒保护提前打断；空帧宽限处理。

### 3.3.3

- 新增分区去重策略：经典（相似度）/ 稳定后朗读 / 跟读增量 / 关闭。

### 3.3.2

- 新增多选区识别与排队朗读；每个区域可单独选择识别目标与四向裁剪；旧配置自动迁移。

### 3.3.1

- 识别后端由内置 PaddleOCR-json 改为外部 PaddleOCR HTTP 服务；新增服务地址、令牌、超时等设置与“测试连接”。
- 移除内置引擎与包内未生效的 PIL，插件体积大幅下降；使用独立插件 ID，可与原版 LION 并存。

## 环境要求

- NVDA 2026.1 或更高（**2026.3 已测试**；配置档案全局化需要 2026.3+）。
- 推荐在本机部署 PaddleOCR HTTP 服务：延迟低，令牌不必出本机。下文以 `http://127.0.0.1:23353` 为例；
  请按实际部署替换地址、端点和令牌。插件不带 OCR 引擎或模型。
- 如果服务在另一台机器，请使用 HTTPS/反向代理并保护令牌；如果服务监听局域网地址，请用防火墙和令牌保护。

## 安装

1. 下载并打开对应的 `.nvda-addon`，在 NVDA 中安装并重启。
2. 打开 NVDA 菜单 → 选项 → 设置：完整版选 **LION 修改版**，lite 选 **LION 修改版 lite**，填写服务地址、端点与令牌。
3. 点“测试 / 获取模型”确认连接。

完整版与 lite 可以同时安装；默认热键相同，需要给其中一个换键。
