# 发布流程

适用于维护者。当前公开版本：**3.3.7**；版本规则：主版本沿用上游 **3.3**，修改版用 **3.3.N** 递增。

## 1. 改版本

同步以下位置：

- `src/manifest.ini` 的 `version` 与 `changelog`；
- `src/locale/zh_CN/manifest.ini` 的 `changelog`；
- `variants/lite/src/manifest.ini` 与 `variants/lite/src/locale/zh_CN/manifest.ini`；
- `src/doc/zh_CN/readme.md`、`src/doc/en/readme.md`、lite 对应 readme；
- `docs/开发文档-中文.md`、`docs/DevGuide-EN.md` 中的版本引用；
- `tests/test_package.py` 的 `EXPECTED_VERSION`、`tests/test_lite_variant.py` 的 `LITE_VERSION`；
- `CHANGELOG.md` 与 `docs/release-notes/v<version>.md`。

公开材料只使用 3.3.1–3.3.7 的版本口径。

## 2. 测试

```powershell
$env:PYTHONIOENCODING = 'utf-8'
$env:PYTHONDONTWRITEBYTECODE = '1'
python -m unittest discover -s tests -p 'test_*.py'
```

完全离线：`$env:LION_SKIP_SERVICE_PROBE = '1'`、`$env:LION_TEST_LIVE = '0'`。
在线测试的令牌用 `LION_TEST_TOKEN` 或 `LION_TEST_TOKEN_FILE`，不要写进仓库。

## 3. 打包

```powershell
pwsh -File scripts\build_addon.ps1 -Variant full -Python python
pwsh -File scripts\build_addon.ps1 -Variant lite -Python python
```

也可以用 `$env:LION_PYTHON` 指定解释器。产物在 `dist/`：

- `LION-modified-<version>.nvda-addon`
- `LION-modified-<version>.files.txt`
- `LION-modified-lite-<version>.nvda-addon`
- `LION-modified-lite-<version>.files.txt`

检查：包内无 `PaddleOCR/`、`PIL/`、`__pycache__`、个人绝对路径、令牌或内部开发编号。

## 4. 提交与 tag

```powershell
git add -A
git status --short
git commit -m "Release LION modified <version>"
git tag -a v<version> -m "LION modified <version>"
git push origin main
git push origin v<version>
```

## 5. 生成源码压缩包与校验值

```powershell
git archive --format=zip --prefix=LION-modified-<version>/ -o dist/LION-modified-<version>-source.zip v<version>
Get-FileHash dist\*.nvda-addon, dist\LION-modified-<version>-source.zip -Algorithm SHA256
```

把包、`.files.txt`、source zip 的 SHA256 写入 `dist/SHA256SUMS.txt`。

## 6. GitHub Release

1. 打开 `https://github.com/xiaoshunxing/LION-modified/releases/new`；
2. 选择 tag `v<version>`；
3. 标题：`LION 修改版 <version>（完整版 + lite）`；
4. 正文：用 `docs/release-notes/v<version>.md`，包含本版变更与公开版本迭代摘要；
5. 附件：两个 `.nvda-addon`、两个 `.files.txt`、source zip、`SHA256SUMS.txt`；
6. 勾选 latest，发布。

Release 只提供当前版本的安装包；历史版本只展示变更，不附旧包。

## 7. 归档

把新包与 `.files.txt` 复制到内部资料库 `../LION-opensource/01-发布物/`（仓库外内部资料），更新 `SHA256SUMS.txt` 与执行记录。
内部资料库位于公开仓库之外，不提交到公开仓库。

## 8. 后续

- NVDA 插件商店需要单独向 NV Access 申请提交权限；
- 自动 Release 工作流可后续加入，并用下一个 3.3.N 版本验证。
