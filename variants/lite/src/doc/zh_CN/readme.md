# LION 修改版 lite

本插件是 [LION 修改版（完整版）](readme.md) 的**简洁版**：界面沿用接近原版 LION 的单区域设置，
识别后端改为外部 PaddleOCR HTTP 服务，并采用与完整版 **3.3.7** 相同的客户端。

## 它做什么

按 `NVDA+Alt+N` 开始/停止。运行期间每隔一段时间对指定区域做一次 OCR，只朗读"变化明显"的文本。
适用于影视字幕、游戏对话、无法被 NVDA 直接读取的界面文字等。

## 与完整版的区别

| | lite（本插件） | 完整版 LION 修改版 |
|---|---|---|
| 识别区域 | **单个区域**（识别目标 + 四向裁剪） | 多个区域，可勾选、排序 |
| 去重方式 | 经典相似度（与原版一致） | 经典 / 稳定后朗读 / 跟读增量 / 关闭（每区域可选） |
| 排队朗读 | 无 | 有 |
| 设置项 | 少，接近原版 | 多（多区域、去重策略等） |
| 客户端 | 与完整版相同 | 相同 |

两个插件可以**同时安装**（插件标识分别是 `LION-modified-lite` 与 `LION-modified`），配置互不覆盖；
但默认热键都是 `NVDA+Alt+N`，同时启用时需要在"输入手势"里给其中一个换键。

## 使用前：启动外部 OCR 服务

本插件**不自带**识别引擎，需要先有可用的 PaddleOCR 服务（本机默认 `http://127.0.0.1:23353`）。

打开 NVDA 菜单 → 选项 → 设置 → **LION 修改版 lite**，填写：

- **OCR 服务地址**：默认 `http://127.0.0.1:23353`（只填基址）
- **模型 / 端点**：默认 `/ocr`；精确档填 `/ocr-acc`；PaddleOCR-VL 填 `/layout-parsing`
- **服务令牌**：服务启动时打印的令牌（服务用 `-NoAuth` 启动时留空）

按"**测试 / 获取模型**"按钮可一次完成：探活 → 读取模型列表 → 校验令牌 → 快端点识别测试。

## 设置项

### 服务

1. **OCR 服务地址**：服务基址，不含端点；也可以把"模型 / 端点"填成完整 URL 指向另一台机器。
2. **模型 / 端点**：可编辑组合框，默认 `/ocr`。
3. **服务令牌**：以密码形式显示；留空则不发送鉴权头。
4. **请求超时（毫秒）**：默认 15000；用 PaddleOCR-VL 时建议加大（上限 120000）。
5. **图像格式**、**返回可视化图（慢）**、**最低识别分数**、**检测最长边**、**错误只提示一次**：
   与完整版相同；检测最长边/最低分数对 `/layout-parsing` 不生效（服务端忽略）。

### 识别

1. **OCR 识别间隔（毫秒）**：默认 1000。
2. **识别目标**：当前对象 / 全屏幕 / 当前窗口 / 当前控件。
3. **文本相似度阈值（%）**：默认 50；新文本与上次朗读的相似度低于该值才朗读。
4. **上方/下方/左侧/右侧裁剪（%）**：从识别目标中裁掉的比例；字幕场景常从上方裁剪约 70%。
5. **识别内容过滤（正则）**：每行一条，匹配到的内容会从识别结果中删除。
