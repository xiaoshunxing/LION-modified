# LION 修改版 lite

本插件是 [LION 修改版（完整版）](https://github.com/xiaoshunxing/LION-modified/blob/main/src/doc/zh_CN/readme.md) 的 lite 版：
界面沿用接近原版 LION 的单区域设置，识别后端使用外部 PaddleOCR HTTP 服务，客户端与完整版 **3.3.7** 相同。

## 它做什么

按 `NVDA+Alt+N` 开始或停止。运行期间每隔一段时间对指定区域做一次 OCR，只朗读变化明显的文本。
适用于影视字幕、游戏对话、无法被 NVDA 直接读取的界面文字等。

## 与完整版的区别

| | 完整版 `LION-modified` | lite `LION-modified-lite` |
|---|---|---|
| 识别区域 | 多区域，可勾选、排序 | 单区域，接近原版 |
| 去重 | 经典 / 稳定后朗读 / 跟读增量 / 关闭 | 经典相似度 |
| 排队朗读 | 有 | 无 |
| 设置项 | 多 | 少，接近原版 |
| 客户端能力 | 相同：模型/端点、模型列表、PaddleOCR-VL 文本提取 | 相同 |

两个插件可以同时安装（ID、包名、配置节都不同），配置互不覆盖；默认热键相同，给其中一个换键即可。

## 使用前：准备外部 OCR 服务

推荐在本机部署 PaddleOCR HTTP 服务：延迟低，令牌不必出本机。
下文以 `http://127.0.0.1:23353` 为例；请按实际部署替换地址、端点和令牌。

打开 NVDA 菜单 → 选项 → 设置 → **LION 修改版 lite**，填写：

- **OCR 服务地址**：示例 `http://127.0.0.1:23353`，只填基址。
- **模型 / 端点**：常见示例 `/ocr`、`/ocr-acc`、`/layout-parsing`；具体以你的服务为准。
- **服务令牌**：按服务端说明获取。

按“**测试 / 获取模型**”可一次完成：探活 → 读取模型列表 → 校验令牌 → 快端点识别测试。

## 设置项

### 服务

1. **请求超时（毫秒）**：初始 15000；使用 `/layout-parsing` 时建议加大（上限 120000）。
2. **图像格式**、**返回可视化图（慢）**、**最低识别分数**、**检测最长边**、**错误只提示一次**：与完整版相同；检测最长边和最低分数对 `/layout-parsing` 不生效（服务端忽略）。

### 识别

1. **OCR 识别间隔（毫秒）**：初始 1000。
2. **识别目标**：当前对象 / 全屏幕 / 当前窗口 / 当前控件。
3. **文本相似度阈值（%）**：初始 50；新文本与上次朗读的相似度低于该值才朗读。
4. **上方/下方/左侧/右侧裁剪（%）**：从识别目标中裁掉的比例；字幕场景常从上方裁剪约 70%。
5. **识别内容过滤（正则）**：每行一条，匹配到的内容会从识别结果中删除。
